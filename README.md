# 🍃 Larang POS — Modern Point of Sale System

Larang POS is a full-stack Point of Sale application designed for modern retail and F&B businesses. It features a decoupled architecture separating the high-performance Angular frontend from the robust Laravel backend.

## 🚀 Tech Stack

- **Frontend:** Angular 19 (Standalone Components, Signals), Tailwind CSS, Ng-Icons.
- **Backend:** Laravel 11 (API Resource, Sanctum Auth).
- **Database:** PostgreSQL / MySQL.
- **Design System:** Custom "Eco-Luxury" Theme (Forest Green & Warm Beige).

## ✨ Key Features (Implemented)

- **🔐 Authentication:** Secure login with role-based access control.
- **📊 Dashboard:** Real-time overview of sales and performance.
- **☕ Product Management:** CRUD operations with grid/list views and stock indicators.
- **📦 Category Management:** Visual category organization with quick insights and z-index optimized dropdowns.
- **🎨 Responsive UI:** Fully responsive layout optimized for desktop and tablet POS usage.
